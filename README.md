## About Me


Backend developer focused on Python and increasingly building AI/LLM-powered systems.


I work on server-side systems: designing APIs, modeling data, handling async workloads,
and running services in production. My core stack is **Django / DRF and FastAPI** backed by
**PostgreSQL, MongoDB, and Redis**, with **Celery** workers, **Docker**-based deployments,
and observability via **OpenTelemetry + SigNoz**.


Recently, my focus has expanded toward the backend side of AI: LLM integrations,
retrieval pipelines (RAG), structured outputs, tool calling, and agent workflows —
built with the same emphasis on reliability, testing, and operability as any backend service.

- **Automation and agent workflows** — scripted pipelines and agent-assisted flows with evaluation and guardrails
